# Blender asset workflow

Use Blender 4.5.3 for authored source scenes. Save editable files under `art/source/`; export game-ready binary glTF files under `art/models/` using `export_glb.py`.

Keep the scene low-poly and material-driven. Apply transforms before export, use readable silhouettes, and avoid relying on texture maps for basic color or shape readability.
